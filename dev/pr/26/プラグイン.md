## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| `_drain` の行の数え方 | 読んだ本文の最後の改行までを読んだ行とし、改行で終わっていない末尾の要素は数えずに次の回に読む。空の要素は改行で終わったものだけを数える | 書きかけの行の JSON が壊れていても読み飛ばさない |
| claude への PATH の渡し方 | `ClaudeSession.start` は、tmux に渡すコマンドの文字列を `PATH={path} {claude} --plugin-dir ...` にし、`path` はシェルの引数として quote する | tmux の PATH の扱いに依らない。`_tmux` は今の PATH のまま tmux を呼ぶ |
| PATH の出所の確認 | PoC で、上の渡し方で claude へ PATH を渡したうえで、`$.process.run` の子プロセスに届く PATH が claude の PATH そのままか、別の出所（シェルの設定・settings.json の `env`・Claude Code 自身の追加）から加わるかを確かめる | PoC PR で確かめ、結論を `## PoC 結果` に書く |
| 継いだ `CLAUDE_CODE_CHILD_SESSION` の除去 | `ClaudeSession.start` は、tmux に渡すコマンドの文字列の頭に `unset CLAUDE_CODE_CHILD_SESSION;` を置く | テストを Claude Code のセッションから流すと、この変数を継ぎ、PATH が空の claude が transcript を保存しない（`## PoC 結果`） |
| `test_error_when_values_unavailable` の仕込み | `path=str(self.session.empty_bin_dir)` のまま、上の 2 つの渡し方で claude へ空のフォルダだけの PATH を渡す（要件.md の案 A） | 子プロセスへ届く PATH は claude の PATH そのままで、`env` は ENOENT で起動できない（`## PoC 結果`） |
| 異常シナリオ（値を引けない）のセットアップ | 仕込みの作り方に合わせて Mock の行の説明を書き換える | 単一ユースケース設計で行う |
| 回帰の確認 | E2E の 5 ファイルを全件流し、#22 の 5 件・#23 の 1 件を含めて pass することを確かめる | 外部 API（Claude のモデル）を呼ぶ |

## PoC 結果

結論: 成立（[PoC PR #27](https://github.com/shuhei1101/alias-inject/pull/27)、[04ec686](https://github.com/shuhei1101/alias-inject/commit/04ec686aa4f78c6b4ea74a048b807f3cdd4c0f9d)）

| 成功条件 | 実測 | 判定 |
| --- | --- | --- |
| claude のプロセスの PATH が空のフォルダだけになる | `/proc/{pid}/environ` の PATH は `{一時フォルダ}/empty-bin` だけ（3 回とも） | 合格 |
| 子プロセスへ届く PATH の出所が分かる | `/usr/bin/env -0` で読んだ子の PATH は claude の PATH と同じ。シェルの設定・settings.json の `env`・Claude Code 自身からの追加は無い | 合格 |
| 名前で起動した `env -0` が起動できない | `ENOENT: Executable not found in $PATH: "env"` の例外（3 回中 3 回） | 合格 |
| 仕込みの無い起動では値を引ける | control は終了コード 0 で `ALIAS_INJECT_E2E_VALUE=value-a` を返した | 合格 |
| 仕込みが `ClaudeSession.start` の引数かファイルの追加で書ける | コマンドの文字列の頭の `unset CLAUDE_CODE_CHILD_SESSION; PATH={path}` だけで書ける | 合格 |

PATH が空のとき、claude は入力を受け付ける状態になり、モデルの返事も返る。
ただし、呼び出し元の Claude Code から `CLAUDE_CODE_CHILD_SESSION=1` を継いでいると、transcript を保存しない（画面に `Transcript saving is off — inherited CLAUDE_CODE_CHILD_SESSION marker` が出る）。
transcript が無いため、テストは返事を待ったまま時間切れになる。PATH を空にしない control では保存された。
この変数を外すか `CLAUDE_CODE_FORCE_SESSION_PERSISTENCE=1` を渡すと保存され、PATH が空のケースも最後まで流れた。変更方針では変数を外す方を採る。

最小再現コードの要点（`poc/run.py` の `_start`）:

```python
claude = str(shutil.which("claude"))
command = f"{claude} --plugin-dir {shlex.quote(str(POC_PLUGIN_DIR))} --model {MODEL}"
if path is not None:
    command = f"PATH={shlex.quote(path)} {command}"
command = f"unset CLAUDE_CODE_CHILD_SESSION; {command}"
session._tmux("new-session", "-d", "-s", session.tmux_name, ..., command)
```

PR の diff の見どころ:

- `poc/plugin/hooks/register.tsx`: `tool.call` で、`/usr/bin/env -0` から子の PATH を読み、`env -0` を名前で起動した結果を文脈として返す
- `poc/run.py` の `PocSession._drain`: #22 の変更方針の読み方（改行で終わった行だけを数える）に差し替え、#22 の読み飛ばしを検証の結果に混ぜないようにしている
