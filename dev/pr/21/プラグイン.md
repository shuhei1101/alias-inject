## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| スキーマ | 要素を「エイリアスの元の行」にする。`id`・`paths`・`metadata` と `metadata.alias_type` のキーを必須にし（`alias_type` の値は `ref` / `custom` のどちらでもよい）、`records`（文字列）と `enabled` を持つ。`metadata` の各キーは `$defs` の値の型（`ref`: `field` を持つ / `custom`: `value` を持つ。`type` が判別子）を指す。行と `metadata` は他のキーを許す | `type`・`fields` と `allOf` の種類ごとの `fields` を削除する。ファイル名は `schemas/aliases.schema.yaml` のまま |
| 種類ごとの必須のキー | 書かないキーも `ref` とみなすため、`alias_type` 以外はスキーマで必須にせず、文書ごとに解決した値が空かで判定する。`alias_type` が `custom` のときは行の検証で、`ref` のときは文書ごとに当てる | env は `url`・`port` の 1 つ以上 |
| 生成した定数 | `scripts/gen-aliases-schema.mjs` で `hooks/lib/aliases-schema.ts` を生成し直す | 直接編集しない |
| 型 | `AliasFields` を削除し、`metadata` のキーごとの値の取り方を `AliasMetadata`（値は `MetadataValue`。`ref` の列の名前か `custom` の値）にし、`AliasConfig` を `id`・`paths`・`records`・`metadata` にする | `AliasType` の 9 つは変えない |
| dev-docs.yaml の読み込み | `documents` の行のうち `metadata.alias_type` を持つ行だけを取り出し、スキーマで検証する。トップレベルの `aliases` は読まない | `documents` が無い・並びでないときの扱いは今の `aliases` と同じ（無ければ 0 件、並びでなければ誤り） |
| 端末の設定 | `global.aliases`・`projects[].aliases` の要素を同じ行の構造で検証する | キー名は `aliases` のまま |
| 文書の取り出し | `records` を書かない行は各ファイルを 1 件の文書にし、書いた行はその配列の要素を文書にする。値の解決は `ref` なら列、`custom` なら値、書かないキーは同じ名前の列 | 照合する語は `name` と `aliases`。`name` が空ならファイル名（拡張子を除く）、`records` の要素は `id` |
| 列の組み立て | `buildFields` は解決した `metadata` の値から種類ごとの列を今と同じ順で並べる | 文脈の書式は変えない |
| サンプル | `settings.sample.yaml` の 9 種類の要素を行の構造にする | - |
| 既存機能への影響 | 設定ファイルの他のキー（`repositories`・`origins`・`max_items` 等）と、変数参照・記録の消去は変えない | 記録の単位の `aliasId` は行の `id` |
