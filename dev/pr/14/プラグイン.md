## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 設定の読み込み | `global` と `projects[]` の要素から、読むリポジトリと `aliases[]` を読む。`sources[]` は読まない | 並べ方は `未確定`（`要件.md`） |
| リポジトリの定義 | 読むリポジトリの `dev-docs.yaml` の `aliases[]` を、更新時刻が変わったときだけ読み直す。`paths` の相対パスは `dev-docs.yaml` のフォルダから解決する | `dev-docs.yaml` が無い・読めないときは、そのリポジトリの定義だけを外して理由を残す |
| 検証 | 端末の設定と `dev-docs.yaml` の `aliases[]` の各要素を `schemas/aliases.schema.yaml` で検証し、合わない要素を外して理由を残す。`id` の重なりは 1 つの設定の中で確かめる | 方法は `未確定`（`要件.md`） |
| 語の組み立て | `fields.match` の列で照合し、文脈に出す語は `fields.title`（無ければ `fields.match` の最初の値）。`type` ごとの列は `fields` の対応から取る | - |
| 文脈と記録 | セクションの見出し・`doc` の `mcp`・記録のキーを、決めた内容に合わせる | `未確定`（`要件.md`） |
| 既存機能への影響 | `enabled`・`origins`・`max_items`・`max_chars`・`exclude`・`heading`・`projects[].match` の扱いと、照合・記録の消去は変えない | - |
