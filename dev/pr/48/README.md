# 複数の物理ファイルにまたがるモジュール構成の設計書を物理ファイルごとに分ける

## 概要

モジュール構成の設計書が物理ファイルと 1 対 1 になり、`design_docs validate` が物理ファイルのエラーを出さなくなる。

## 背景

[Issue #47](https://github.com/shuhei1101/alias-inject/issues/47) の報告。
`develop` で `design_docs validate` が、`スキーマ.yaml`・`入口.yaml`・`記録.yaml` の要素の `container` が 2 つ以上の物理ファイルにまたがるとして 4 件のエラーを出す。
[PR #46](https://github.com/shuhei1101/alias-inject/pull/46) の作業中に見つかったもので、#46 が増やしたエラーではない。
