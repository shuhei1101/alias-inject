## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| スキーマ | `type` の `enum` に `skill`・`tool`・`path`・`env`・`avoid` を追加し、`allOf` に種類ごとの必須・任意の `fields` を追加する。列の名前の `$defs` に `fieldSkill`・`fieldTool`・`fieldPath`・`fieldPort`・`fieldReplacement` を追加し、`examples` に各種類の例を追加する | env の必須の fields は `未確定`（[要件](./要件.md)） |
| 生成した定数 | `scripts/gen-aliases-schema.mjs` で `hooks/lib/aliases-schema.ts` を生成し直す | 直接編集しない |
| 型 | `AliasType` に 5 種類を追加し、`AliasFields` に `skill`・`tool`・`path`・`port`・`replacement` を追加する | - |
| 列の組み立て | `buildFields` に種類ごとの列を [要件](./要件.md) の表の順で追加する。値の無い列は並べない | 値の書式（コードの書式で囲むか）はインターフェース定義設計で決める |
| セクション | `SECTION_HEADINGS` の url の後ろに、スキル・ツール・パス・環境・避ける語の順で追加する | - |
| サンプル | `settings.sample.yaml` に追加した種類の要素の例を追加する | 既存の 4 要素は変えない |
| 既存機能への影響 | term・doc・command・url の `fields`・追加する列・書式と、設定ファイルの他のキーは変えない | - |
