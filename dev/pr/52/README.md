# ツールの結果の本文にも用語の照合をかけ、引用の文脈を追加する

## 概要

Bash・Read・MCP などのツールで読んだ本文に登録した用語や文書の名前があると、メッセージで送ったときと同じく、その語の引用の文脈がモデルに追加されるようになる。

## 背景

[Issue #51](https://github.com/shuhei1101/alias-inject/issues/51) の要望。
用語・文書のエイリアスとの照合は `prompt.submit`（`handlePromptSubmit`）で送信されたメッセージに対してだけ行われる。
`tool.call`（`handleToolCall`）は [PR #15](https://github.com/shuhei1101/alias-inject/pull/15) でツールの結果の `!{名前}` に環境変数の値を追加する処理として入ったもので、用語の照合は行わない。
そのため、dev-docs の `search_docs` などで読んだ本文に登録した語があっても文脈は追加されない。
