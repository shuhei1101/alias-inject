# 要件

## 要望

Claude Code のツールの結果の本文（Bash・Read・Grep・WebFetch・MCP のツールなど）を、メッセージと同じ用語・エイリアスと照合し、当たった語の引用の文脈をツールの結果の後ろに追加する。

- `tool.call` で、ツールの結果の本文の `!{名前}` への環境変数の値の追加はそのまま残し、引用の文脈と両方を合わせて返す
- 照合する語・上限（`max_items` / `max_chars`）・除外する語（`exclude`）・見出し・出所の扱いは、メッセージの照合と同じ設定を使う
- 照合するツールは全てのツールを既定にし、設定ファイルでツールの名前を指定して照合から外せるようにする
- セッションで追加した語の記録はメッセージの送信と共有し、メッセージかツールの結果のどちらかで一度追加した語は再び追加しない
- サブエージェントのツールの結果は、メインの会話とは別の記録で扱う。サブエージェントで追加した語は、メインの会話では追加済みにならない
- 読んでいる文書そのものの語は追加しない（Read の `file_path` が語の指す文書のパスに当たるとき、MCP のツールの引数の文書の ID が語の ID に当たるとき）
- 当たった語が上限を超えるときは、本文に出た回数の多い順に並べてから上限で切る
- 次の結果は照合しない: エラーの結果・拒否された呼び出し・本文の無い結果
- 照合で例外が起きても、ツールの結果は止めずにそのまま返す

出た回数の多い順の並べ替えはツールの結果の照合だけに当て、メッセージの照合は今の最初に出た位置の順のままにする（インターフェース定義設計で決定）。

照合から外すツールは設定ファイルの `exclude_tools`（ツールの名前の並び）で指定し、`projects[]` では `exclude` と同じく `global` の後ろに追加する（インターフェース定義設計で決定）。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| ツールの呼び出しの入力（Bash のコマンド・Write の内容など）への照合 | 要望はツールの結果の本文への照合 | 予定なし |
| ツールの結果の本文の書き換え | 要望は本文を変えずに文脈を追加すること | 予定なし |
| 設計書の `tags` 列の変更 | 別の Issue の作業で、今回の変更では直らない | [#39](https://github.com/shuhei1101/alias-inject/issues/39) |
