# alias-inject を Claude Code の mod の単独のプラグインとして立ち上げる

## 概要

利用者が alias-inject をマーケットプレイスからユーザースコープで入れられ、hooks モジュールの入口が読み込まれるようになる。

## 背景

[Issue #3](https://github.com/shuhei1101/alias-inject/issues/3) の要望。
設計書も実装も無いリポジトリで、Claude Code の mod の単独のプラグインを立ち上げる。
入口の上に載せる機能（入力の語の照合と引用の文脈の追加）は [Issue #1](https://github.com/shuhei1101/alias-inject/issues/1) が作り、この PR の後に着手する。
