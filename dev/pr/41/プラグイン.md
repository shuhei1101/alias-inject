## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| スキーマ | 行に `alias_type`（9 つの enum）を置き、`id`・`paths`・`alias_type` を必須にする。`metadata` は任意にし、各キーの値を列名の文字列（`minLength: 1`）にする | `$defs` の `metadataValue`・`refValue`・`customValue`・`aliasTypeValue` を削除する。ファイル名は `schemas/aliases.schema.yaml` のまま。行と `metadata` は他のキー（`schema`・`body_file`・`tags` 等）を許す |
| 生成した定数 | `scripts/gen-aliases-schema.mjs` で `hooks/lib/aliases-schema.ts` を生成し直す | 直接編集しない |
| 型 | `MetadataValue` を削除し、`AliasMetadata` を `Partial<Record<AliasKey, string>>` にする。`AliasConfig` に `alias_type: AliasType` を持たせ、`ALIAS_KEYS` から `alias_type` を外す | `AliasType` の 9 つは変えない |
| 値の解決 | `resolveMetadata` は、書いたキーは列名の列、書かないキーは同じ名前の列から取る。`.` を含む列名は入れ子の列をたどる | `custom` の分岐を削除する |
| 文書ごとの種類の確認 | 種類は行で 1 つに決まるため、文書ごとの `alias_type` の確認を削除し、行の `alias_type` で必須のキーを確かめる | `alias_type の値 … は引用の種類にありません` の失敗は無くなる |
| dev-docs.yaml の読み込み | `documents` の行のうち `alias_type` を持つ行だけを取り出し、スキーマで検証する。`alias_type` を持たず `metadata.alias_type` を持つ行は、外した理由を warnings に入れる | 理由は移し替えが要ることが分かる文言にする |
| 端末の設定 | `global.aliases`・`projects[].aliases` の行を同じスキーマで検証する。旧い構造の行はスキーマに合わない行として外す | キー名は `aliases` のまま |
| 文書の名前 | `name` が空の文書は、ファイルの文書はファイル名（拡張子を除く）を使う。`records` の要素の取り方は `要件.md` の `未確定` | - |
| サンプル | `settings.sample.yaml` の 9 種類の行を、行の `alias_type` と列名の `metadata` にする | - |
| 既存機能への影響 | 照合する語・文脈の書式・設定ファイルの他のキー（`repositories`・`origins`・`max_items` 等）と、変数参照・記録の消去は変えない | 記録の単位の `aliasId` は行の `id` のまま |
