# 要件

## 要望

develop から、今ある E2E のテストと、E2E だけが使用する補助と実行方法の記載を削除し、単体テストと結合テストが全件 pass することを確認する。

| 対象 | 変更 |
| --- | --- |
| `tests/e2e/`（`support/harness.py`、単一ユースケース 5 本・複合ユースケース 1 本のテスト） | フォルダごと削除する |
| テスト実行方法の層「E2E テスト」 | 実行コマンド・説明・`ALIAS_INJECT_E2E_*` の環境変数・前提・個別実行を削除し、全件実行を `未確定` にする |
| 設計書のシナリオと、その対応テストファイル（`test_file`） | 変えない |

E2E だけが使用するシード・フィクスチャ・モック・CI のジョブ・Playwright の設定・`package.json` の script・開発コマンドは、develop に無い。
`tests/e2e/` の補助は `tests/unit/`・`tests/integration/` から参照されていない。
