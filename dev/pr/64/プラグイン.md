## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 作業場所の絞りのキー | `schemas/aliases.schema.yaml` のエイリアスの元の行に、作業場所の glob の並びを持つ省略できるキー `scope.cwd` を追加する | 端末の設定の行と `dev-docs.yaml` の `documents` の行の両方に記載できる。照合する作業場所は `$.session.root()` |
| glob の照合 | 先頭の `~` を展開し、`*` はフォルダの区切りを除く任意の文字列、`**` は任意の深さのフォルダとして作業場所の絶対パスと照合する | dev-docs の `sources[].scope` と同じ書き方にする。`hooks/lib/loader.ts` に `matchPathGlob` を追加し、区切りの照合は既存の `matchSegment` を使用する |
| 行の選択 | 設定と `dev-docs.yaml` の行を集めた後、作業場所が絞りのどの glob にも当たらない行を外し、外した行の YAML を読まない | 照合条件（`inject_when`）・`exclude` の処理は変えない |
| 誤った値 | 並びでない・空の並び・文字列でない要素を持つ絞りは、行を照合から外して理由を debug log に出す | 既存の行の検証と同じ扱い |
| 既存機能への影響 | 絞りを記載しない行の照合の結果は今と変わらない | 既存の単体・結合・E2E を回す |
| 性能 | 絞りの判定は行ごとに 1 回の glob の照合で、非機能要件の待ち時間に収める | 非機能要件テストで測る |
