# エイリアスの元の行ごとに、引用の文脈を追加する作業場所（cwd）を glob で絞れるようにする

## 概要

利用者がエイリアスの元の行ごとに作業場所の glob を記載でき、その行の語は glob に当たる作業場所の会話でだけ引用の文脈が追加されるようになる。

## 背景

[Issue #62](https://github.com/shuhei1101/alias-inject/issues/62) の要望（急ぎ）。
端末の設定の `global.aliases` に追加したエイリアスの元の行は、全てのプロジェクトの会話で照合される。
話し合い「何でも会話」の用語集を `global.aliases` で読ませたところ、「共通」「通知」「アカウント」のような一般的な単語が、関係の無いプロジェクトの会話でも案内されるようになった。
今は `projects[].match` の要素の `aliases` に同じ行を作業場所の数だけ記載すれば絞れるが、1 行に glob を並べて絞る手段は無い。
行ごとに作業場所の glob で絞る設定を alias-inject に追加することは、Issue の `## 決まったこと` のとおり起票前の話し合いで決めた。
