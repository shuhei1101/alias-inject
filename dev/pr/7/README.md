# 入力の語を設定の YAML と照合し、引用の文脈をモデルに追加する

## 概要

利用者（と ai-monitor の自動のセッション）が入力した文に、設定ファイルで指定した YAML の用語・エイリアスが出ると、その語の引用の文脈（意味・文書の ID・コマンド・URL など）がモデルにだけ追加されるようになる。

## 背景

[Issue #1](https://github.com/shuhei1101/alias-inject/issues/1) の要望。
入力に出た用語は、今はモデルが MCP の本文の中で出会ったときしか拾われない。
[#5](https://github.com/shuhei1101/alias-inject/pull/5) で置いた hooks モジュールの空の入口 `hooks/register.tsx` の上に、照合と文脈の追加の処理を作る。
決定の経緯は Issue の `## 必読` が挙げる話し合いの記録（D-48・D-64〜D-74・D-86〜D-92）にある。
