## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 設計書の移動 | `dev/設計書/{種別}/` を `docs/{kind}/` へ移し、ai-monitor#3307 の変換 v0.4.0（`python -m ai_monitor.design_docs convert --from v0.2.0 --to v0.4.0`）で ID を振ってから、ファイル名を `{ID}.yaml`（モジュール構成は `{ID}.{lang}.yaml`）にする | 変換はモジュール構成を物理ファイルごとの設計書（`MOD-1` 〜 `MOD-17`）に分ける。ID の構造は project-index#13 と同じ `{接頭辞}-{連番}` |
| 設計書の中のパス | 他の設計書を指す `dev/設計書/...#` を、変換の前に移した後のパスへ書き換え、変換で `{ID}#{項目のパス}` と `id:` のリンクにする。変換が書き換えない箇所（`inherits`・シナリオの図の `click`・本文の相対パス）は手で修正する | - |
| Schema | `dev/テンプレート/*.schema.yaml` を削除し、ai-monitor#3307 の `schemas/{kind}.schema.yaml` を写す（共通の Schema の `doc_visibility` が `public` / `internal` を持つ） | project-index#13 と同じく変換のスクリプト `schemas/conversions/` は写さない。`schemas/aliases.schema.yaml` と生成の `scripts/gen-aliases-schema.mjs` は変えない |
| 目次 | `dev/index.yaml`・`dev/設計書/index.yaml` の行を `docs/index.yaml` にまとめ、行が種類のフォルダを指すようにする。各種類のフォルダの `index.yaml` を書き、`README.md` は `python -m ai_monitor.design_docs publish` で生成する | 中身の無い目次だけのフォルダは削除する |
| 公開ドキュメント | `docs/はじめに/`・`docs/使い方/`・`docs/リファレンス/` を `docs/guide/` にまとめ、分類を `category` で持つ。分類のトップページと上タブを作る | `docs/guide/変更履歴.md` のタグで固定したリンクは修正しない |
| 公開範囲 | 移した設計書は `visibility: internal`、公開ドキュメントは `visibility: public` を持つ。`docs/_config.yml` を作り、`exclude` に `internal` だけの種類のフォルダと `pr/`・`mock/`・`generated/` を記載する | - |
| 配信の設定 | `dev-docs.yaml` の各行を移した後の `paths`・`schema` にし、`visibility` を `metadata` に対応づける。目次の行と `docs/guide/files.yml` の行を project-index#13 と同じ構造で持つ | 文書の ID が変わるため、移した後に `search_docs` で件数を確認する |
| 既存機能への影響 | プラグインの振る舞いは変えない | `skills/global-setup/SKILL.md` が指すページのパスだけを修正する |
