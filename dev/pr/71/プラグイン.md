## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 設計書の移動 | `dev/設計書/{種別}/` を `docs/{kind}/` へ移し、ファイル名を `{ID}.yaml` にする。`モジュール構成/プラグイン/` のサブフォルダは除いてフラットにする | ID の略号は project-index#13 に統一する（`ARCH`・`NFR`・`MOD`・`CFG`・`TP`・`CMD`。シナリオ・インターフェース定義・外部ライブラリの略号もこれに倣う） |
| 設計書の中のパス | 他の設計書を指す `dev/設計書/...#` を移した後のパスにする | dev-docs の `trace_related` で参照元を検索して漏れを確認する |
| Schema | `dev/テンプレート/*.schema.yaml` を `schemas/{kind}.schema.yaml` へ移し、`$ref` と各設計書の `$schema` を修正する。共通の Schema の `visibility` を `public` / `internal` にする | `schemas/aliases.schema.yaml` と生成の `scripts/gen-aliases-schema.mjs` は変えない |
| 目次 | `dev/index.yaml`・`dev/設計書/index.yaml` の行を `docs/index.yaml` にまとめ、行が種類のフォルダを指すようにする。各種類のフォルダに `index.yaml` と生成した `README.md` を配置する | 中身の無い目次だけのフォルダは削除する |
| 公開ドキュメント | `docs/はじめに/`・`docs/使い方/`・`docs/リファレンス/` を `docs/guide/` にまとめ、分類を `category` で持つ。分類のトップページと上タブを作る | `docs/guide/変更履歴.md` のタグで固定したリンクは修正しない |
| 公開範囲 | 移した設計書は `visibility: internal`、公開ドキュメントは `visibility: public` を持つ。`docs/_config.yml` を作り、`exclude` に `internal` だけの種類のフォルダと `pr/`・`mock/`・`generated/` を記載する | - |
| 配信の設定 | `dev-docs.yaml` の各行を移した後の `paths`・`schema` にし、`visibility` を `metadata` に対応づける。目次の行と `docs/guide/files.yml` の行を project-index#13 と同じ構造で持つ | 文書の ID が変わるため、移した後に `search_docs` で件数を確認する |
| 既存機能への影響 | プラグインの振る舞いは変えない | `skills/global-setup/SKILL.md` が指すページのパスだけを修正する |
