## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| スキーマの置き場所 | `schemas/aliases.schema.yaml` をリポジトリの直下の `schemas/` に置く。サブシステムは増やさず、プラグインのリポジトリが持つファイルとして扱う | アーキテクチャ図の `repository.layout` に追加する |
| スキーマの中身 | `要件.md` の `### スキーマ` のとおり。`type` ごとの必須・任意の `fields` は `allOf` の `if`（`type` の値）/ `then`（`fields` の `required` と `additionalProperties: false`）で分ける | - |
| バージョン | `要件.md` の `### バージョン` のとおり、リリースのタグをスキーマのバージョンにする | - |
| 既存機能への影響 | hooks モジュールと設定の読み込みは変えない | - |
| 単体テスト | `tests/unit/schemas/aliases.schema.test.ts` で、スキーマの YAML を `hooks/vendor/js-yaml.mjs` で読み、`type` の値と `type` ごとの必須・任意の fields を `要件.md` の表と突き合わせる | `claude plugin test .` で流れる |
