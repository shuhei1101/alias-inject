# 要件

## 要望

`dev-docs.yaml` の `documents[]` の設計書の行で、目次の `index.yaml` を外すための先頭の文字の否定（`[!i]*.yaml`）を通常の glob（`*.yaml`）に戻し、行の `exclude: [index.yaml]` で外す。

- 対象は `paths[]` に `[!i]*.yaml` を持つ行（architecture・interface・scenario・test_procedure・module・library・config・dev_command・nonfunctional）の全ての要素にする
  - module の行は `dev/設計書/モジュール構成/**/*.yaml` にする
- 否定の glob を説明しているコメント（`# index.yaml は目次なので、paths の先頭の文字の否定（[!i]）で外す`）は、`exclude[]` で外す説明に書き換える
- `exclude[]` のキーは dev-docs の [設定](https://github.com/shuhei1101/dev-docs/blob/develop/docs/%E3%83%AA%E3%83%95%E3%82%A1%E3%83%AC%E3%83%B3%E3%82%B9/%E8%A8%AD%E5%AE%9A.md) の `documents[].exclude[]` に従う
- dev-docs の develop のクローンで `dev-docs.yaml` を読み込み、設定のスキーマの違反と各文書の Schema の検査の違反が 0 件で、各行の文書が書き換える前と同じ件数であることを確かめる

Issue が挙げた `[!R]*.md` の行（`docs/はじめに/`・`docs/はじめに/コアコンセプト/`・`docs/リファレンス/`）は、[PR #41](https://github.com/shuhei1101/alias-inject/pull/41) で公開ドキュメントを `docs/files.yaml` の `records: files` の行で読む構成に変わり、develop に残っていない。
