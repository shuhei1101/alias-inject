# dev-docs.yaml の documents[] の否定の glob（[!i]*.yaml）を exclude[] へ書き換える

## 概要

`dev-docs.yaml` の設計書の行で、目次の `index.yaml` を先頭の文字の否定の glob ではなく `exclude[]` で外す。

## 背景

[Issue #38](https://github.com/shuhei1101/alias-inject/issues/38) の要望。
[PR #35](https://github.com/shuhei1101/alias-inject/pull/35) で置いた設計書の行は、`paths[]` の `[!i]*.yaml` で目次の `index.yaml` を外しており、`i` で始まる設計書も配信から漏れる。
dev-docs に `documents[].exclude[]` が入った（[shuhei1101/dev-docs PR #29](https://github.com/shuhei1101/dev-docs/pull/29)、起点 [shuhei1101/dev-docs#26](https://github.com/shuhei1101/dev-docs/issues/26)）ので、ファイル名で外す書き方へ書き換える。
