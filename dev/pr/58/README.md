# 文書ごとに AND・OR・NOT の照合条件を持たせ、名前が当たっても条件に当たらない文書を案内しない

## 概要

利用者が文書ごとに引用の文脈を追加する条件を AND・OR・NOT で記載でき、文書の名前・エイリアスが入力に当たっても、その条件に当たらなければ引用の文脈が追加されなくなる。

## 背景

[Issue #57](https://github.com/shuhei1101/alias-inject/issues/57) の要望。
alias-inject は、文書の `name`・`aliases` の単語が照合する本文に 1 つ出たら、その文書の引用の文脈を追加する（`findHits`）。
照合する本文はメッセージ（`prompt.submit`）と、[PR #52](https://github.com/shuhei1101/alias-inject/pull/52) で加えたツールの結果（`tool.call`）で、どちらも同じ照合を使う。
名前が一般語の文書は関係の無い本文にも当たり、knowledge の React の規約『フォルダ構成』（`react-core-folder-structure`）が Python のフォルダ構成の会話でも案内される。
照合条件を alias-inject にだけ入れること、文書ごとに 1 つ持たせること、構造を dev-docs の `filter` と同じにすることは、Issue の `## 決定` のとおり起票前の話し合いで決めた。
