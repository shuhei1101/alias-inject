## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 照合条件のキー | `ALIAS_KEYS` と `schemas/aliases.schema.yaml` の `metadata` に照合条件のキーを追加し、値を取る列の名前を指せるようにする | キーは `inject_when` |
| 照合条件の読み込み | 語の組み立てで照合条件の列の値を語に持たせ、構造（条件・束・比べ方・3 レイヤーまで・空の束なし）を検査する | 照合条件が誤っている文書は照合から外す |
| 照合条件の評価 | 照合条件を、照合した本文に対して評価する関数を追加する。正規化は照合の正規化（`normalize`）と同じにし、`case_sensitive` が true の条件は正規化せずに比べる | 比べる対象は照合した本文（`field: text`）、比べ方は `contains`・`not_contains`。置き場所はモジュール構成設計で決める |
| 当たった語の絞り込み | `prompt.submit`・`tool.call` で `findHits` の後に、照合条件に当たらない語を除く | 並び順（位置の順・出た回数の順）は変えない |
| 既存機能への影響 | 照合条件を持たない文書の照合の結果は今と変わらない | 既存の単体・結合・E2E を回す |
| 性能 | 照合条件の評価は当たった語の文書にだけ行い、非機能要件の待ち時間に収める | 非機能要件テストで測る |
