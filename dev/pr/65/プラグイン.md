## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 設定ファイルのパスの取得 | `readConfigPath` が、`ALIAS_INJECT_CONFIG` を要件の順で参照し、無ければ `XDG_CONFIG_HOME`（無い・空なら `~/.config`）の下の `alias-inject/settings.yaml` を返却する | 参照する順は要件の `## 要望` |
| 既定のパスに設定ファイルが無いとき | `$.fs.stat` で無いことを確認したら null を返却し、今の `ALIAS_INJECT_CONFIG` が無いときと同じく debug log を出さない | `ALIAS_INJECT_CONFIG` で指したファイルが無いときは今どおり debug log に出す |
| `global-setup` のスキル | プラグインの直下の `skills/global-setup/SKILL.md` に、要件の流れの手順を記載する | 質問は AskUserQuestion で、既定値を推奨の選択肢にする（dev-docs の `global-setup` と同じ） |
| 既存機能への影響 | `settings.json` の `env.ALIAS_INJECT_CONFIG` を記載した端末は、同じ設定ファイルを参照し続ける | 破壊的変更なし |
