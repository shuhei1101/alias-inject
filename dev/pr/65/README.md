# 端末の設定を既定のパスとシェルの環境変数からも参照し、セットアップのスキル global-setup を作る

## 概要

利用者が `~/.claude/settings.json` の `env` に記載しなくても既定のパスの端末の設定で引用の文脈を受け取れ、スキル `global-setup` で端末の設定を作れるようになる。

## 背景

[Issue #63](https://github.com/shuhei1101/alias-inject/issues/63) の要望。
端末の設定は `~/.claude/settings.json` の `env` の `ALIAS_INJECT_CONFIG` からだけ参照し、無いと何も追加しない。
セットアップのスキルも無く、利用者が手順を実行している。
自作のツール（dev-docs・mdmark・rule-inject・alias-inject）で端末の設定の既定のパスと環境変数の名前を統一し、端末の設定を持つツールに `global-setup` を持たせることは、Issue の `## 決まったこと` のとおり起票前の話し合いで決めた。
