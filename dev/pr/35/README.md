# alias-inject の既存の文書を dev-docs.yaml に載せて dev-docs で配信する

## 概要

alias-inject の既存の文書（`docs/` の公開ドキュメントと `dev/設計書/` の設計書）を、dev-docs で配信してタグで引けるようになる。

## 背景

[Issue #34](https://github.com/shuhei1101/alias-inject/issues/34) の要望。
[PR #32](https://github.com/shuhei1101/alias-inject/pull/32)（起点 [Issue #30](https://github.com/shuhei1101/alias-inject/issues/30)）で置いた `dev-docs.yaml` の `documents[]` は、判定フローチャートのページ 1 枚の行だけを持つ。
ほかの文書は dev-docs で配信されておらず、タグでも引けない。
#32 の要件.md の `## スコープ外` で切り出した項目で、既存の文書を dev-docs に対応させる作業はリポジトリごとの Issue で扱う（A-19・D-101・D-103）。

## 計画書

| --- | --- |
| [要件](./要件.md) | 要望の整理・影響するユースケース・更新ドキュメント・スコープ外 |
