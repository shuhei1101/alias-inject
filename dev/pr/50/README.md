# dev-docs.yaml を設定のバージョン 3 へ移し替え、docs の文書でないファイルを除外する

## 概要

`dev-docs.yaml` を dev-docs の設定のバージョン 3 へ移し替え、`docs/` の文書でないファイルを配信から外して、`check_project` の違反と索引に無いファイルを 0 件にする。

## 背景

[Issue #49](https://github.com/shuhei1101/alias-inject/issues/49) の要望。
端末の dev-docs に alias-inject の develop の worktree を配信元として登録したが、`dev-docs.yaml` の設定のバージョンが `1` のままで、今の dev-docs が読める `3` と合わず、起動のたびに警告が出る。
`check_project`（2026-10-30）では、違反は 0 件で、管理用の YAML（`docs/files.yaml`）に無いファイルが 19 件ある。
