# 要件

## 要望

`dev-docs.yaml` を dev-docs の設定のバージョン 3 へ移し替え、`docs/` の文書でないファイルを配信から外して、`check_project` の違反と索引に無いファイルを 0 件にする。

- dev-docs の develop のクローンで `migrate --source dev-docs.yaml --plan` が出す次の手順を当て、`version` を `"3"` にする
  - `documents[].type` の yaml を削除する
  - `metadata.alias_type` の固定値を、行の `alias_type` へ移す
  - `metadata` の `ref` を、読む列の名前の文字列にする
  - `tags`（タグのマスター）を削除する（破壊的。マスターのファイルは消さない）
- `docs/files.yaml` に行の無い 19 件を次のとおり扱う
  - `docs/_theme/` の下の 9 件（`nav.yml`・`nav.project.yml`・HTML・CSS・JS・`llms.txt`・`search.json`）と、`docs/` の配下の目次の `index.yaml` 5 件は、文書でないので `docs` の行の `exclude[]` にファイル名の glob で入れる。`mermaid.min.js` は dev-docs の除外の条件（`.min.js`）で既に数えない
  - `docs/` の配下の `README.md` 5 件（`docs/`・`はじめに/`・`はじめに/コアコンセプト/`・`リファレンス/`・`使い方/`）は、`docs/files.yaml` に行を追加する
- dev-docs の `check_project` で、違反と索引に無いファイルが 0 件で、移し替えの警告が出ないことを確かめる
