# エイリアスを登録するかの判定フローチャートを使い方に追加し、dev-docs で配信する

## 概要

文書を指す名前をエイリアスに登録する人が、登録するかを判定フローチャートで決められるようになる。
判定フローチャートのページは dev-docs で配信し、タグで引けるようになる。

## 背景

[Issue #30](https://github.com/shuhei1101/alias-inject/issues/30) の要望。
エイリアスを登録する条件は knowledge の規約『タグと用語の登録』の条件の表だけで、文書を指す名前 1 つに順に当てる形になっていない（D-108）。
一般語を登録すると、関係ない文章の語にツールチップが出る。
判定の対象を持つ alias-inject に判定フローチャートとして置き、dev-docs でタグを付けて配信する（D-110）。
同じ話し合いで、ほかの判定フローチャートを [shuhei1101/rule-inject#63](https://github.com/shuhei1101/rule-inject/issues/63)・[shuhei1101/dev-docs#18](https://github.com/shuhei1101/dev-docs/issues/18)・[shuhei1101/knowledge#86](https://github.com/shuhei1101/knowledge/issues/86) が扱う。
