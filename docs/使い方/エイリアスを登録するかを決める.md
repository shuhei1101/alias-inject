# エイリアスを登録するかを決める

文書を指す名前を、エイリアスとして登録するかを決める判定フローチャート

```mermaid
flowchart TD
  START([文書を指す名前])
  Q1{会話・Issue・本文で、実際にその名前で呼ばれたか? ※1}
  Q2{複数の文書や用語に当てはまる一般語か? ※2}
  Q3{1〜2 文字か、ほかの語の一部としてよく出る語か? ※3}
  Q4{全角半角・大文字小文字の正規化で吸収できる表記ゆれか? ※4}

  R1([登録しない])
  R2([登録しない])
  R3([登録しない])
  R4([登録しない])
  R5([登録する])

  START --> Q1
  Q1 -->|NO| R1
  Q1 -->|YES| Q2
  Q2 -->|NO| Q3
  Q2 -->|YES| R2
  Q3 -->|YES| R3
  Q3 -->|NO| Q4
  Q4 -->|NO| R5
  Q4 -->|YES| R4
```

- **※1 その名前で呼ばれた**: その文書を指す語として使われた実例が、会話・Issue・本文に残っている。略称・英語名・旧名で参照される場合も含む
- **※2 一般語**: 複数の文書や用語に当てはまる語。登録すると、ツールチップが別の文書に紐付く。例: 設定・手順
- **※3 1〜2 文字の語・ほかの語の一部**: 照合は部分文字列で当たるため、別の語の中でも当たる。例: 「印」は「印刷」に当たる
- **※4 正規化で吸収できる表記ゆれ**: 照合の前に、入力と語の両方へ NFKC・英字の小文字化・前後の空白の除去をかける。例: 「ＡＰＩ」と「API」は同じ語になるので、両方は登録しない
