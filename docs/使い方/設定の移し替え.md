# 設定の移し替え

端末の設定と dev-docs.yaml を、旧い `aliases[]` の構造（`type`・`fields`）から行の構造へ移し替える手順

## 前提

旧い `type`・`fields` の構造は読まない。
移し替えるまでは、旧い構造の要素は照合から外れ、外した理由が Claude Code の debug log に出る。
dev-docs.yaml のトップレベルの `aliases` も読まない。

行の構造は [エイリアスのスキーマ](../リファレンス/エイリアスのスキーマ.md)、設定の項目は [設定ファイル](../リファレンス/設定ファイル.md) を参照する。

## 手順

<!-- steps -->

1. 設定ファイルのバックアップをコピーする。

   ```bash
   mkdir -p ~/.config/alias-inject/bk
   cp ~/.config/alias-inject/settings.yaml ~/.config/alias-inject/bk/settings.yaml
   ```

2. 設定ファイルの `global.aliases` と `projects[].aliases` の要素を、[書き換えの対応](#書き換えの対応) で行の構造に書き換える。

3. 読むリポジトリの `dev-docs.yaml` のトップレベルの `aliases` の要素を、同じ対応で `documents` の行に移し、トップレベルの `aliases` を削除する。

4. `paths` が指す YAML の最上位が並びのものは、並びを 1 つのキーの下に移し、その行の `records` にキーの名前を指定する。
   1 件ずつ別のファイルにする場合は、`records` を指定しない。

5. 用語を含む文を Claude Code に入力し、モデルに追加される文脈にその用語が出ることを確かめる。
   設定ファイルと dev-docs.yaml に `fields` のキーが残っておらず、debug log に要素を外した理由の行が出ていないことも確かめる。

<!-- /steps -->

## 書き換えの対応

| 旧い構造 | 行の構造 |
| --- | --- |
| `id`・`enabled`・`paths` | そのまま |
| `type` | `metadata.alias_type`。`{type: custom, value: 旧い type の値}` |
| `fields.title` の列 | `metadata.name`。`{type: ref, field: 列の名前}` |
| `fields.match` の最初の列（`fields.title` が無いとき） | `metadata.name`。`{type: ref, field: 列の名前}` |
| `fields.match` の残りの列 | `metadata.aliases`。`{type: ref, field: 列の名前}` |
| `fields.id`・`description`・`related`・`avoid`・`command`・`cwd`・`url`・`skill`・`tool`・`path`・`port`・`replacement` | 同じ名前の `metadata` のキー。`{type: ref, field: 列の名前}` |

- `metadata` のキーは、記載しなければ同じ名前の列の `ref` とみなす。列の名前がキーと同じなら記載を省ける
- 照合する語は `name` と `aliases` の 2 つの列に限る。`fields.match` に 3 つ以上の列を挙げていたときは、`aliases` の列にまとめる
## 移し替えの例

旧い構造。

```yaml
global:
  aliases:
    - id: terms
      type: term
      paths:
        - terms/*.yaml
      fields:
        id: id
        match:
          - name
          - aliases
        description: description
        related: related
```

行の構造。

```yaml
global:
  aliases:
    - id: terms
      paths:
        - terms/*.yaml
      metadata:
        alias_type:
          type: custom
          value: term
```

`id`・`name`・`aliases`・`description`・`related` は、同じ名前の列から取る。
dev-docs.yaml は、同じ内容を `documents` の行にする。

```yaml
documents:
  - id: terms
    paths:
      - terms/*.yaml
    metadata:
      alias_type:
        type: custom
        value: term
```
