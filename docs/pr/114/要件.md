# 要件

## 要望

AI Monitor `v0.4.0` の配布物のうち、alias-inject に有るものを `v0.4.0` に揃え、配布先の反映作業を alias-inject で済ませる。

| 分類 | 終わりの条件 |
| --- | --- |
| サイトのレイアウト | `python -m ai_monitor.distribution import-site --version v0.4.0` で `docs/_theme/` を取り込み、直下の控え `ai-monitor-theme.yaml` の版が `v0.4.0` になっている |
| 追従のバージョン | [ai-monitor-version.ini](https://github.com/shuhei1101/alias-inject/blob/develop/ai-monitor-version.ini) が `v0.4.0` になっている |
| 配布先の反映作業 | [反映作業/index.yaml](./反映作業/index.yaml) の作業ごとに、確認スクリプトが alias-inject で効いている結果を返す |

配布先の反映作業の dry-run の結果は次のとおり（各作業のフォルダの `dry-run.log`）。

| 作業 | dry-run | alias-inject の状態 |
| --- | --- | --- |
| プロジェクトの索引の移動 | skipped | 直下に `rules.yaml` があり、`docs/rules.yaml` が無い |
| 配布先の移した文書の写しの削除 | skipped | 写しのファイルが無い |
| 配布先の dev-docs への移行 | ok | 配信元 `alias-inject` が `project-index.yaml` で project-index の端末の設定に登録されている |
| 配布先のエージェント統合への追従 | skipped | `agent_context.yaml`・`.claude/agent-settings/` が無い |
| プロジェクトの索引の設定ファイルへの移行 | skipped | `.claude/settings.json` が無い |
| 各プロジェクトのスキーマの参照への移行 | skipped | `project-index.yaml` の `schema` は [#106](https://github.com/shuhei1101/alias-inject/pull/106) で knowledge の参照へ移行済みで、スキーマのコピーが無い |
| 配布先の規約のパスの追従 | skipped | `rules.yaml` は `rules: []` で、`agent_context.yaml` が無い |
| 配布先のデータの設計書の作成 | skipped | ER 図の設計書（`docs/er/`）が無い |

配布元のスクリプトのうち「配布先の dev-docs への移行」「各プロジェクトのスキーマの参照への移行」「配布先のデータの設計書の作成」は直下の `dev-docs.yaml` を読む。
alias-inject は [#81](https://github.com/shuhei1101/alias-inject/pull/81) で `project-index.yaml` へ改名済みのため、写したスクリプトの `dev-docs.yaml` を `project-index.yaml` へ、「配布先の dev-docs への移行」の端末の設定を `~/.config/project-index/settings.yaml` へ読み替えた。
