# AI Monitor v0.4.0 の配布物へ追従する

## 概要

alias-inject が、AI Monitor v0.4.0 のサイトのレイアウトと配布先の反映作業に揃った状態になる。

## 背景

[Issue #113](https://github.com/shuhei1101/alias-inject/issues/113) の要望。
AI Monitor の `v0.3.0..v0.4.0` の配布物の差分（[比較](https://github.com/shuhei1101/ai-monitor/compare/v0.3.0...v0.4.0)）への追従で、[ai-monitor-version.ini](https://github.com/shuhei1101/alias-inject/blob/develop/ai-monitor-version.ini) は `v0.3.0` のまま。
前の版への追従は [#44](https://github.com/shuhei1101/alias-inject/issues/44)（[PR #46](https://github.com/shuhei1101/alias-inject/pull/46)）。
