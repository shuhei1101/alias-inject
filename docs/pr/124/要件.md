# 要件

## 要望

テスト実行方法の層 TL-1（単体テスト）・TL-2（結合テスト）の `run_runner` で、`run_id` を取った後に run を GitHub の API で参照できるまで待ってから `gh run watch` を呼ぶ。

| 分類 | 終了の条件 |
| --- | --- |
| 待ち | `gh api "repos/{owner}/{repo}/actions/runs/$run_id?exclude_pull_requests=true"` を 1 秒おきに最大 10 回試し、参照できた時点で `gh run watch` へ進む |
| 参照できないとき | `実行 {run_id} を 10 秒参照できません` を標準エラーに出し、終了コード 1 で終える |
| 既存の振る舞い | 参照できた後の `gh run watch --exit-status`・`gh run view --log`・終了コードは変えない |

待ちの回数と間隔は、同じ修正を入れた project-index の [PR #139](https://github.com/shuhei1101/project-index/pull/139)（TP-1）と claude-balancer の TP-275-1 に統一する。
