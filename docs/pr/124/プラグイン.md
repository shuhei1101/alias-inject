## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| TL-1・TL-2 の `run_runner` | `run_id` を取った後、`gh api` で run を 1 秒おきに最大 10 回参照し、参照できたら `gh run watch` へ進む。参照できなければ `実行 {run_id} を 10 秒参照できません` を標準エラーに出して終了コード 1 で終える | 2 つの層のコマンドは同じ文字列にする |

## テスト結果

### 単体

なし（変更はテスト実行方法のコマンドだけで、プラグインのコードを変えないため、対応する単体テストが無い）

### 結合

なし（変更はテスト実行方法のコマンドだけで、プラグインのコードを変えないため、対応する結合テストが無い）

### 待ちの処理の動作確認

`run_runner` に追加した待ちの部分だけを、worktree で `run_id` を変えて実行した。

| `run_id` | 結果 |
| --- | --- |
| 実在する run（`gh run list -L1` の 44008288015） | 1 回目の `gh api` で参照でき、終了コード 0 で `gh run watch` へ進む |
| 実在しない run（1） | 10 回試した後に `実行 1 を 10 秒参照できません` を標準エラーに出し、終了コード 1 で終える |
