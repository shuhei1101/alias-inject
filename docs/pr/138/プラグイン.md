## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 表示の手段 | 入力・ツールの結果と同じ `showAdded` を `quoteAnswer` から呼び、`$.ui.log(文面, { to: 'transcript' })` で出す | `turn.step` から呼んだときの表示は PoC 検証で確認する |
| 表示する内容 | その回に `$.session.append` で会話へ追加した単語を `文脈を追加: {単語}（{id}）、…` の 1 行で表示する | 文面は #133 で決めたもの |
| 表示の時期 | `$.session.append` の後に表示する | `deny` のときは表示しない（[要件](./要件.md)） |
| オンとオフ | 既存の `show_added` に従う | 設定のキーは増やさない |
| サブエージェント | `e.agentId` があるときも表示する | 行はメインの会話の画面に出る（`tool.call` では #135 で確認済み） |
| エラー処理 | 表示に失敗したら debug log に出し、応答は止めない | 既存の `showAdded` の扱いのまま |
| 既存機能への影響 | 会話に追加する行の中身と記録、応答の文とチャンクは変えない | - |

## PoC 結果

| 検証構成 | 成功条件 | 結果 | PoC PR | 補足 |
| --- | --- | --- | --- | --- |
| メインの会話の `turn.step` | 応答の文の後にトークン A の行が画面に出る | ✅ 出た | [#139](https://github.com/shuhei1101/alias-inject/pull/139)（closed） | Claude Code 2.1.328・Sonnet 5.5。`claude-balancer exec` で `--plugin-dir` 起動 |
| サブエージェントの `turn.step` | `agent-{agentId}` のトークン A の行がメインの会話の画面に出る | ✅ 出た | 同上 | サブエージェントの途中の文・最後の文の 2 行が出た |
| 表示の行がモデルに届かない | 記録で A の行が `system`・`informational`、モデルが A を回答できない | ✅ 種類が一致し、回答は B だけ | 同上 | 送信した要求の記録（`api-request-blob`）に A は 1 度も入らなかった |
| 追加した行がモデルに届く | 次の入力でモデルが B を回答できる | ✅ 回答できた | 同上 | サブエージェントは、途中の文で追加した B を Bash の後の最後の文で書き写した |
| 途中の文 | 途中の文の後に Bash を呼ぶ要求でも A の行が出て、同じターンの Bash の結果の後に B が届く | ✅ 出て、届いた | 同上 | A の行は Bash の実行の表示の後に出た |
| 応答の文 | 記録の assistant の行と画面の応答の文が一致し、A の行がその後ろに出て入力待ちに戻る | ✅ 一致した | 同上 | - |

結論: 成立。
`turn.step` の中で `$.session.append`（`type: user`）の後に `$.ui.log` の `transcript` を呼んでも、追加した `user` の行は次の要求でモデルに届き、`transcript` の行は利用者の画面にだけ出る。
サブエージェントの `turn.step` から呼んだ行も、メインの会話の画面に出る。

- サブエージェントの最後の文で追加した B（IF-7 の制約のとおり届かない行）に対しても、A の行は画面に出た。表示の行と、モデルに届くかどうかは独立している
- 1 回目のサブエージェントへの依頼（「見えている TOKEN- の文字列を列挙する」）は、Sonnet 5.5 の安全判定（`reasoning_extraction`）で止められた。「会話に届いた『PoC の追加の行:』で始まるメッセージを書き写す」へ言い換えて通した。検証の観点には影響しない
- 起動は `claude-balancer exec --client ai-monitor --kind short` で行い、従量課金の API は使っていない

最小再現コードの要点（[01b64f4](https://github.com/shuhei1101/alias-inject/commit/01b64f4) の `hooks/register.tsx`）:

```ts
on('turn.step', async function* ($, e, next) {
  const result = yield* next(e)
  if (typeof result.answer !== 'string' || result.answer === '') return result
  const where = e.agentId === undefined ? 'main' : `agent-${e.agentId}`
  await $.session.append({
    message: { type: 'user', content: [{ type: 'text', text: `PoC の追加の行: ${token('B', where)}` }] },
    ...(e.agentId === undefined ? {} : { agentId: e.agentId }),
  })
  $.ui.log(token('A', where), { to: 'transcript' })
  return result
})
```

diff の見どころは `hooks/register.tsx` だけで、他はマーケットプレイスとプラグインの名前を `alias-inject-poc` に変えた差分。
