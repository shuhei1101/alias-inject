# 要件

## 要望

応答の文（`turn.step`）の照合で引用の文脈を会話に追加したときに、入力・ツールの結果と同じく、追加した単語と文書の ID を利用者の画面に表示する。

- 文面は入力・ツールの結果と同じ `文脈を追加: {単語}（{id}）、…` の 1 行にし、`$.ui.log` の `to: 'transcript'` で出す
- 表示するのは、その回に会話へ追加した単語だけにする（記録済み・上限・照合条件で追加しなかった単語は表示しない）
- 設定 `show_added` が false のときは表示しない
- 表示は、応答の文・チャンク・会話に追加する行を変えない
- 表示に失敗しても、応答は止めない

`未確定`: `$.session.append` が `deny` を返却したときに表示するか（決める工程: インターフェース定義設計）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | 行の追加が拒まれたときは表示しない | 画面の行が、モデルに届いた文脈と一致する | 記録に入った単語が画面に出ない |
| B | 記録に入れた後に、行の追加の結果によらず表示する | 入力・ツールの結果と同じく、記録に入れた単語を出す | モデルに届いていない単語が「文脈を追加」と表示される |

推奨: A

表示の文面は「文脈を追加」で、利用者はモデルに文脈が届いたと受け取るため。
