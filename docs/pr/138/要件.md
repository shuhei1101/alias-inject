# 要件

## 要望

応答の文（`turn.step`）の照合で引用の文脈を会話に追加したときに、入力・ツールの結果と同じく、追加した単語と文書の ID を利用者の画面に表示する。

- 文面は入力・ツールの結果と同じ `文脈を追加: {単語}（{id}）、…` の 1 行にし、`$.ui.log` の `to: 'transcript'` で出す
- 表示するのは、その回に会話へ追加した単語だけにする（記録済み・上限・照合条件で追加しなかった単語は表示しない）
- 設定 `show_added` が false のときは表示しない
- 表示は、応答の文・チャンク・会話に追加する行を変えない
- 表示に失敗しても、応答は止めない

`$.session.append` が `deny` を返却して行を追加できなかった回は表示しない（表示の文面「文脈を追加」は、モデルに文脈が届いたことを示すため）。
