# 要件

## 要望

リポジトリの直下の配信元の設定 `dev-docs.yaml` を `project-index.yaml` へ改名する（中身は変えない）。

develop へマージした直後に、次の 2 つの端末の設定の alias-inject の行を改名後のパスへ書き換える。

| 端末の設定 | 書き換える行 | 書き換えた後の値 |
| --- | --- | --- |
| `~/.config/dev-docs/settings.yaml` | `sources[]` の `config: /mnt/c/Users/shuhe/repo/alias-inject/dev-docs.yaml` | `/mnt/c/Users/shuhe/repo/alias-inject/project-index.yaml` |
| `~/.config/alias-inject/settings.yaml` | `global.repositories[]` の `config: /mnt/c/Users/shuhe/repo/alias-inject/.claude/worktrees/develop/dev-docs.yaml` | `/mnt/c/Users/shuhe/repo/alias-inject/.claude/worktrees/develop/project-index.yaml` |

書き換えた後に、次を満たす。

- develop の worktree を作業場所にした `search_docs`（`source`: `alias-inject`・`view`: `count`）の件数が、書き換える前と同じ
- alias-inject が alias-inject の配信元の設定の文書のエイリアスを照合から外さない

作業 PR が develop へ入ると、配信元の設定を develop から読む側（dev-docs の配信・develop の worktree を読む alias-inject）で `dev-docs.yaml` が無くなるため、書き換えはマージの直後に行う。
