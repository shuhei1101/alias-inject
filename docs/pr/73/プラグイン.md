## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 照合する単語 | `alias_type` が `term` の文書の `avoid` の値（文字列か並び）から、やめた言い方ごとに `## 避ける語` の項目を作り、やめた言い方を照合する単語にする | 項目の作り方（用語ごとに 1 つか、やめた言い方ごとに 1 つか）と記録のキーはモジュール構成設計で決める |
| 文脈の書式 | `## 避ける語` のセクションに、やめた言い方を単語として並べ、子に `replacement: {用語の name}` を並べる | `alias_type` が `avoid` の行の単語と同じ書式 |
| 一般的な単語の除外 | 既存の `global.exclude` で除外する | `未確定`（[要件](./要件.md) の `## 要望`） |
| 既存機能への影響 | 用語の `name`・`aliases` の照合と `## 用語` のセクション、`alias_type` が `avoid` の行の照合は変えない | - |
| ツールの結果 | `tool.call` も同じ項目で照合するため、追加の分岐を持たない | - |
