# 要件

## 要望

`alias_type` が `term` の行の文書（用語）が `avoid` の列に持つやめた言い方を、照合する単語に加える。
入力かツールで読んだ本文にやめた言い方が出たら、`## 避ける語` のセクションに、やめた言い方を単語として並べ、箇条書きの子に `replacement` として用語の `name` を並べる。

- 書式は `alias_type` が `avoid` の行の単語と同じにする
- 用語の `name`・`aliases` が出たときの `## 用語` のセクションの案内は、今と変えない
- `avoid` の列の値は、文字列と文字列の並びの両方を受け付ける（`aliases` と同じ）
- やめた言い方も、会話ごとに 1 回だけ文脈を追加する
- 端末の設定のキーは追加しない。`metadata.avoid` を記載しない行は、今の既定のとおり同じ名前の列（`avoid`）から取る

`未確定`: 一般的な単語のやめた言い方（準備・入口・特性 など）を照合から除外する手段（決める段: インターフェース定義設計）

| 案 | 内容 |
| --- | --- |
| A | 既存の `global.exclude`（照合しない単語）で除外する。新しいキーを追加しない |
| B | 用語のやめた言い方の照合だけから除外する単語の並びを、設定ファイルに追加する |
| C | 除外する手段を用意しない |

推奨: A

`global.exclude` は既に全ての照合から単語を除外するキーで、端末の設定のキーを増やさずに済むため。
一般的な単語は用語の名前としても照合したい場面が少ない。
