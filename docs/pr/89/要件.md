# 要件

## 要望

`docs/`（`docs/pr/`・`docs/_theme/` を除く）の設計書・公開ドキュメントと、`hooks/` の `.ts`・`.tsx` のコメントに残る NG の単語を、knowledge の [AI slop の単語の対応表](https://github.com/shuhei1101/knowledge/blob/develop/docs/word-list/word-list-ai-slop.yaml)（develop）の OK の単語へ置き換える。

- 終わりの条件: 対象のファイルを対応表の `pattern`（`allow` を除く）で照合し、ヒットが 0 件になる。ヒットを残す箇所は、残す理由をスコープ外に記載したものだけにする
- 置き換えで文の意味・設計の内容・コードの動作を変えない
- 設定のキー・スキーマ・引用の文脈の見出し・警告の文言など、コードが出力する文字列は変えない

`未確定`: プロジェクトの用語として使用している「語」（照合する語・語の指す文書・文脈に出す語）の呼び名（決める段: 単一ユースケース設計。置き換えを始める前に決める）

| 案 | 内容 |
| --- | --- |
| A | 「単語」へ変更する（照合する単語・単語の指す文書・文脈に出す単語） |
| B | 「語」のまま維持し、用語以外の「語」だけを置き換える |

推奨: A

スキーマの注釈（[PR #83](https://github.com/shuhei1101/alias-inject/pull/83)）が既に「照合する単語」「文脈に出す単語」と記載し、[PR #87](https://github.com/shuhei1101/alias-inject/pull/87) で見出しも「使用しない単語」にしたため、設計書・公開ドキュメントを揃えると呼び名が 1 つになる。
