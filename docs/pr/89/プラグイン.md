## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 用語「語」 | 「単語」へ置き換える | - |
| 置き換え先 | 対応表の `ok` から、文の意味に合う単語を選ぶ（読む → 参照する、書く → 記載する、当たる → 該当する 等） | `note` に意味の限定がある単語（引く・起こす・当たる・旧い）は、その意味のときだけ置き換える |
| 設計書 | シナリオ → インターフェース定義 → モジュール構成（設定 CFG-1 を含む）の順に置き換える | 設計の内容は変えない |
| 公開ドキュメント・その他の設計書 | ドキュメント修正の工程で `docs/guide/`・`docs/architecture/`・`docs/library/`・`docs/nonfunctional/`・`docs/dev-command/`・`docs/test-procedure/`・目次を置き換える | `変更履歴.md` は過去の PR のタイトルのため置き換えない |
| コードのコメント | 実装の工程で `hooks/` の `//`・`/** */` のコメントを置き換える | 文字列リテラルは変えない |
| 既存機能への影響 | コードの動作・出力は変わらない | 単体・結合テストは実行のみで回帰を確認する |
