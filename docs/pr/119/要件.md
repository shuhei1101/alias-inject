# 要件

## 要望

[project-index.yaml](https://github.com/shuhei1101/alias-inject/blob/d87dba0/project-index.yaml) に `nav` を記載し、dev-docs の画面のタブとサイドバーを規約『開発ドキュメントのナビゲーション』（knowledge の `dev-docs-navigation`）に合わせる。

<!-- table: {"kind": "data"} -->

| 分類 | 終了の条件 |
| --- | --- |
| タブの並び | タブが左から「はじめに・使い方・設計書・リファレンス」の順に並ぶ。規約の順のうち、配信元に文書の無い「規約・コード・用語集」は配置しない |
| タブの中身 | 「はじめに」「使い方」「リファレンス」は公開ドキュメント（`docs/guide/files.yml`）の `category` が同じ値の文書を並べる。「設計書」はアーキテクチャ図・非機能要件・シナリオ・インターフェース定義・モジュール構成・外部ライブラリ・設定・開発コマンド・テスト実行方法・フォルダ構成を並べる |
| サイドバーのグループ | 「設計書」のタブで、設計書を種類ごとのグループにまとめる。入れ子は 2 階層まで |
| グループの中の並び | 手順の順か重要さの順にし、名前の順にしない。`auto` の並びが違うときは `page` を並べて順を指定する |
| 目次を並べない | フォルダの目次（`kind: index`）が、どのタブとサイドバーにも並ばない。目次の文書は `search_docs` で検索できる状態のまま残す |
| 公開ドキュメントの配信 | 公開ドキュメントの行の `exclude` が `docs/guide/files.yml` 自体を除外しない。`check_project` の「無いパス」に `docs/guide/files.yml` が出ない |
| 画面の確認 | 修正した設定を dev-docs で開き、タブの並びと数・サイドバーのグループ・目次や内部のファイルが出ていないか・文書をスクロールした状態をスクリーンショットで確認し、reviewer の確認を受ける |

<!-- /table -->

## 画面の確認
