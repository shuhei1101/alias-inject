## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 設計書・公開ドキュメント | 例の名前の `dev-docs.yaml` を `project-index.yaml` に置換し、`index.yaml` を変えたフォルダの README.md を生成し直す | ドキュメント修正で行う |
| コメント・スキーマ・設定の例・スキル | 同じく置換し、`hooks/lib/aliases-schema.ts` はスキーマから生成し直す | 実装で行う |
| debug log の文言 | `dev-docs.yaml を読めません` の `dev-docs.yaml` を `project-index.yaml` にする | 単体テストは `YAML を読めません` の部分一致で確かめており、変更は要らない |
| 既存機能への影響 | `repositories[].config` に指定したパスを読む振る舞いは変えない | - |

## テスト結果

### ドキュメント修正

なし（設計書・公開ドキュメントの例の名前の置換だけで、規約『V字モデル』の対応表で関係する単体・結合テストが無い）
