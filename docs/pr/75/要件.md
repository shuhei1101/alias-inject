# 要件

## 要望

設計書・公開ドキュメント（`docs/guide/`）・`settings.sample.yaml`・コードのコメントと debug log の文言・`schemas/aliases.schema.yaml` の description（生成した `hooks/lib/aliases-schema.ts` を含む）・`skills/global-setup/SKILL.md` が例に使う配信元の設定のファイル名を、`dev-docs.yaml` から `project-index.yaml` にする。

- `dev-docs.local.yaml` は origin/develop のどのファイルにも出ないため、`project-index.local.yaml` への置換の対象が無い
- `repositories[].config` に指定したパスを読む振る舞いは変えない。利用者の設定はそのまま使用できる
- 置換した後、`git grep dev-docs.yaml` の結果がスコープ外の行（変更履歴・過去の PR ドキュメント・リポジトリ自身の配信元の設定・テストのフィクスチャ）だけになる
- 既存の単体・結合テストが全 pass し、lint が通る
