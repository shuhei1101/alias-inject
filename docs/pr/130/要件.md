# 要件

## 要望

`docs/` の Markdown に `mdmark upgrade` を適用し、旧書式のマーカー（`<!-- table: data -->`・`<!-- steps -->`）を JSON の記載へ移す。
移行の報告に挙がる記載（拡張・`libraries` のマーカー、書き出さない記載）は、手で記載し直す。

終わりの条件:

- `mdmark check` が `legacy_mark` を出さない
- 完了したら [shuhei1101/mdmark#478](https://github.com/shuhei1101/mdmark/issues/478) にその旨をコメントする

## テスト結果

文書の Markdown と `mdmark.config.yaml` だけを変え、コードを変えないため、関係する単体・結合テストは無い。

移行は、`docs/**/*.md` を `build.include` に持つ一時の設定（`mdmark.config.yaml` の複製）を作り、`npx github:shuhei1101/mdmark#v0.13.0 upgrade --yes --config {一時の設定}` に手元のバージョン `v0.10.0` を渡して適用した（v0.11.0 の手順で 22 件の文書のマーカーを書き換え、v0.13.0 の手順の書き換えは 0 件）。
同じ一時の設定での `mdmark check` は `legacy_mark` が 0 件。`<!-- steps -->` は引数を持たないため、移行の対象にならない。
