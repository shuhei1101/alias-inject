## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 応答の文のイベント | `turn.step` に処理を登録し、`next(e)` の結果の `answer`（モデルへの要求 1 回ごとの応答の文）を照合する | `## PoC 結果` |
| 応答の文の照合 | 応答の文を入力と同じ設定と単語で照合し、その会話で初めて出た単語の文脈を `$.session.append`（`type: 'user'`、サブエージェントでは `agentId`）で追加する | 文脈はその会話の次のモデルへの要求に届く |
| 書き込む内容の照合 | `tool.call` で `next(e)` の後に、全てのツールの引数の文字列の値を結果の本文と合わせて照合する | IF-2 |
| 書き込んだ文書そのものの単語 | Write・Edit の `file_path` が単語の指す文書のパスと一致する単語を除外する | Read と同じ除外 |
| 記録 | 入力・ツールの結果と同じ記録（セッション ID、サブエージェントではサブエージェントの ID との組）を使用する | - |
| 既存機能への影響 | 入力の照合・ツールの結果の本文の照合・変数参照の値の追加の振る舞いは変えない | SC-3・SC-4・SC-7 の回帰を確認する |
| プラグインの説明 | `.claude-plugin/plugin.json` の description を、書き込む内容と応答の文の照合を含む文言にする | プラグインの一覧に表示される文言のため、reviewer の合格の後にユーザーに確認する |

最小再現コードの要点（[hooks/poc-response.ts](https://github.com/shuhei1101/alias-inject/blob/77aa0b24651c8fc4262b65384bf4be8060d52c6d/hooks/poc-response.ts)）:

```ts
export async function* pocTurnStep($, e, next) {
  const result = yield* next(e)            // turn.step はストリームのイベントで、処理は async generator
  if (result.answer.includes('ZEBRA')) {
    await $.session.append({
      message: { type: 'user', content: [{ type: 'text', text: 'PoC の目印: ...' }] },
      ...(e.agentId ? { agentId: e.agentId } : {}),  // サブエージェントの会話へ追加する
    })
  }
  return result
}
```
