# Claude Code が書き込む内容と応答の文でも単語を照合して引用の文脈を追加する

## 概要

Claude Code が書き込む内容と、Claude Code の応答の文に出た単語にも、引用の文脈が追加されるようにする。

## 背景

[Issue #132](https://github.com/shuhei1101/alias-inject/issues/132) の要望（MindStella の話し合いのスレッド TH-1262 の利用者の依頼）。
今の hooks モジュールは、入力（`prompt.submit`）とツールの結果の本文（`tool.call`）だけを照合する。
書き込みのツール（Write・Edit・MCP の書き込みのツール）の結果は短い完了の文なので、書き込んだ内容の単語には文脈が追加されない。
応答の文のイベントには処理を登録していない。
