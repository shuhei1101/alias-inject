## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 表示の手段 | `$.ui.log(文面, { to: 'transcript' })` で会話の記録に出す。文面の先頭にプラグインの名前を入れない（Claude Code が付ける） | `## PoC 結果` で確定 |
| 表示する内容 | その回に `context` へ追加した単語と文書の ID を `文脈を追加: {単語}（{id}）、…` の 1 行で表示する | 文面はユーザーが決めた（[確認ログ](./確認ログ.yaml)） |
| 表示する量 | 追加した単語を全て 1 回の表示にまとめる | - |
| オンとオフ | 設定ファイルのキー `show_added`（既定 true）で止められるようにする | - |
| エラー処理 | 表示に失敗したら debug log に出し、入力の送信とツールの結果は止めない | 既存の `logDebug` と同じ扱い |
| 既存機能への影響 | `context` に追加する文脈の中身と記録は変えない | - |

## PoC 結果

| 検証構成 | 成功条件 | 結果 | PoC PR | 補足 |
| --- | --- | --- | --- | --- |
| `--plugin-dir`・入力 | `prompt.submit` の行が画面に出る | ✅ 出た | [#135](https://github.com/shuhei1101/alias-inject/pull/135)（closed） | Claude Code 2.1.327・Sonnet 5.5 |
| `--plugin-dir`・メインの Read | agentId なしの `tool.call` の行が画面に出る | ✅ 出た | 同上 | - |

| モデルの入力 | 会話の記録で、モデルへ送信するメッセージの種類になっていない | ✅ `type: "system"`・`subtype: "informational"` | 同上 | サブエージェントの記録には残らない |
| モデルの入力 | モデルがトークンを回答できない | ✅ 「見ていない」と応答 | 同上 | - |
| 入力とツールの結果 | フックが無いときと同じく返る | ✅ 返った | 同上 | - |
| マーケットプレイスから `--scope local` で入れた構成 | `prompt.submit` の行が画面に出る | ✅ 出た | 同上 | 記録の種類も `--plugin-dir` と同じ |

結論: 成立。
`$.ui.log` の `to: 'transcript'` は、メインの会話・サブエージェントのどちらの `tool.call` から呼んでも、利用者の画面と会話の記録に `● {プラグインの名前}: {文面}` の行で出て、モデルの入力には入らない。

- タスクの完了の通知（`origin` が `task-notification`）でも `prompt.submit` が呼ばれ、行が出た。表示の対象にするかは、既存の `origins` の判定に従う
- `--scope local` の登録は、worktree ではなくリポジトリの直下の `.claude/settings.local.json` に記載された。検証の後に登録を削除し、ファイルも削除した

最小再現コードの要点（[a568c7e](https://github.com/shuhei1101/alias-inject/commit/a568c7e) の `hooks/register.tsx`）:

```ts
export const register: Register = (on) => {
  on('prompt.submit', async ($, e, next) => {
    if (e.command === undefined) $.ui.log(token('prompt'), { to: 'transcript' })
    return next(e)
  })
  on('tool.call', async ($, e, next) => {
    const result = await next(e)
    const where = e.agentId === undefined ? 'main' : `agent-${e.agentId}`
    $.ui.log(token(`tool-${e.tool}-${where}`), { to: 'transcript' })
    return result
  })
}
```

diff の見どころは `hooks/register.tsx` だけで、他はマーケットプレイスとプラグインの名前を `alias-inject-poc` に変えた差分。
