## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 表示の手段 | hooks モジュールから利用者の画面に出し、モデルの入力に入らない API を使用する | `未確定`（[要件](./要件.md)。決める工程: PoC 検証） |
| 表示する内容 | その回に `context` へ追加した単語と文書の ID | 文面はインターフェース定義設計でユーザーに確認する |
| 表示する量 | 追加した単語を全て 1 回の表示にまとめる | `未確定`（[要件](./要件.md)。決める工程: インターフェース定義設計） |
| オンとオフ | 設定ファイルのキーで止められるようにする | `未確定`（[要件](./要件.md)。決める工程: インターフェース定義設計） |
| エラー処理 | 表示に失敗したら debug log に出し、入力の送信とツールの結果は止めない | 既存の `logDebug` と同じ扱い |
| 既存機能への影響 | `context` に追加する文脈の中身と記録は変えない | - |
