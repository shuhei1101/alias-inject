# 要件

## 要望

入力（`prompt.submit`）とツールの結果（`tool.call`）で単語がヒットし、引用の文脈を追加したときに、追加した単語と文書の ID を利用者の画面に表示する。

- 表示するのは、その回に `context` へ追加した単語だけにする（記録済みで追加しなかった単語は表示しない）
- 文脈を追加しなかった回（ヒットが無い・全て記録済み・無効の設定）は何も表示しない
- 表示は、モデルへの入力（入力の文と `context`）を変えない
- 表示に失敗しても、入力の送信とツールの結果は止めない

表示には `$.ui.log` を `to: 'transcript'` で使用する。
利用者の画面と会話の記録に出て、モデルの入力に入らないことを PoC 検証で確認した（[プラグイン](./プラグイン.md) の `## PoC 結果`）。

表示する行は、追加した単語を全て `文脈を追加: {単語}（{id}）、…` の 1 行に並べる（単語の数は `max_items` で上限がある）。
表示は設定ファイルのキー `show_added`（既定は true）で `global`・`projects` ごとに止められる。
文面とキーの名前はユーザーが決めた（[確認ログ](./確認ログ.yaml)）。
