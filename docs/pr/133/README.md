# 単語がヒットして文脈を追加したことを、利用者の画面にも表示する

## 概要

利用者が、入力とツールの結果で単語がヒットして引用の文脈が追加されたときに、ヒットした単語と文書の ID を画面で確認できるようになる。

## 背景

[Issue #131](https://github.com/shuhei1101/alias-inject/issues/131) の要望（MindStella の話し合い TH-1262 で利用者が依頼）。
alias-inject は、`prompt.submit` と `tool.call` の結果の `context` に引用の文脈を追加するだけで、文脈はモデルにだけ届く。
利用者は、どの単語がヒットして何が追加されたかを画面で確認できない。
