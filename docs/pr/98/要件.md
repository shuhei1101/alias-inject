# 要件

## 要望

`.claude-plugin/plugin.json` の description、`settings.sample.yaml`・`rules.yaml` のコメントに残る NG の単語を、knowledge の [AI slop の単語の対応表](https://github.com/shuhei1101/knowledge/blob/develop/docs/word-list/word-list-ai-slop.yaml)（develop）の OK の単語へ置き換える。

- 終わりの条件: 3 ファイルを対応表の `pattern`（`allow` を除く）で照合し、ヒットが 0 件になる
- 置き換えるのはコメントと description の文言だけで、設定のキー・値とルール索引の `rules` は変えない

プロジェクトの用語「語」（照合する語・文脈に出す語）は、#89 の決定のとおり「単語」へ置き換える。
`plugin.json` の description はプラグインの一覧に表示される文言のため、置き換え後の文言をユーザーに確認する。
