## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 用語「語」 | 「単語」へ置き換える | #89 の確認ログの決定 |
| 置き換え先 | 対応表の `ok` から、文の意味に合う単語を選ぶ（読む → 参照する、書く → 記載する、当たる → 該当する 等） | `note` に意味の限定がある単語は、その意味のときだけ置き換える |
| `plugin.json` の description | 実装の工程で置き換え、reviewer の合格の後に置き換え後の文言をユーザーに確認する | プラグインの一覧に表示される文言 |
| `settings.sample.yaml`・`rules.yaml` | 実装の工程でコメントだけを置き換える | キー・値は変えない |
| 既存機能への影響 | コードの動作・出力は変わらない | 単体・結合テストを全件実行し、`claude plugin validate .` で回帰を確認する |
