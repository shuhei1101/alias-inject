# フォルダ構成の設計書（layout）を作成し、今のフォルダ構成をレビューの観点で確認する

## 概要

開発者が、このリポジトリのフォルダ構成の設計書（layout）を参照し、フォルダ構成の問題をレビューの観点で洗い出せるようになる。

## 背景

[Issue #66](https://github.com/shuhei1101/alias-inject/issues/66) の要望。
このリポジトリにはフォルダ構成の設計書が無く、フォルダ構成の問題をレビューで洗い出せない。
フォルダ構成のテンプレート（[shuhei1101/knowledge#219](https://github.com/shuhei1101/knowledge/issues/219)）・設計の手順（[shuhei1101/ai-monitor#3267](https://github.com/shuhei1101/ai-monitor/issues/3267)）・設計書の検査の knowledge のスキーマの参照への切り替え（[shuhei1101/ai-monitor#3188](https://github.com/shuhei1101/ai-monitor/issues/3188)）は、どれも closed になった。
今のフォルダの一覧は、アーキテクチャ図 `ARCH-1` の `repository.layout` に 1 行で書かれている。
