# 今ある E2E のテストと、E2E だけが使う部品を develop から削除する

## 概要

develop から、今ある E2E のテストと、E2E だけが使う補助と実行方法の記載を削除する。設計書のシナリオは残す。

## 背景

[Issue #68](https://github.com/shuhei1101/alias-inject/issues/68) の要望。
0.x の間は E2E を回さず修正もしないため、今ある E2E は仕様の変更で古くなり、エージェントが参照して誤解する。
E2E はメジャーのリリースの前に全体の仕様が固まった状態で作り直し、シナリオと対応テストファイルの記載はそのときのマーカーとして残すと決まった。
