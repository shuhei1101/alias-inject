# 要件

## 要望

alias-inject のリポジトリを、Claude Code の mod の単独のプラグインとして立ち上げる。
機能（入力の語の照合と文脈の追加）は載せず、[#1](https://github.com/shuhei1101/alias-inject/issues/1) が入口の上に処理を作れる状態にする。

- `.claude-plugin/plugin.json` を持つ単独のプラグインにする。MCP サーバーは持たない
- `.claude-plugin/marketplace.json` でリポジトリ自身をマーケットプレイスにし、利用者がユーザースコープで入れられる
- `hooks/hooks.json` の `modules` から TypeScript の hooks モジュール `hooks/register.tsx` を読む。モジュールは処理を登録しない空の入口にする
- 利用者の手元の Claude Code（ターミナル版）でプラグインを入れたとき、読み込みのエラーを出さずにモジュールが読まれる
- `claude plugin validate` が通る
- `claude plugin test` でテストを流せ、テストが 1 件以上 pass する
- `tsc -p` で型の確認が通る
- フォルダ構成とファイルの置き場所を rule-inject（[shuhei1101/rule-inject](https://github.com/shuhei1101/rule-inject)）の単独のプラグインのプロジェクトにそろえる

## 影響するユースケース

なし。
この PR は空の入口だけを置き、利用者から見える動きを持たない。
機能のユースケースは [#1](https://github.com/shuhei1101/alias-inject/issues/1) が作る。
