# AI Monitor v0.5.0 の配布物へ追従する

## 概要

alias-inject が、AI Monitor v0.5.0 のサイトのレイアウトと配布先の反映作業を取り込んだ状態になる。

## 背景

[Issue #117](https://github.com/shuhei1101/alias-inject/issues/117) の要望。
AI Monitor の `v0.4.0..v0.5.0` の配布物の差分（[比較](https://github.com/shuhei1101/ai-monitor/compare/v0.4.0...v0.5.0)）への追従で、[ai-monitor-version.ini](https://github.com/shuhei1101/alias-inject/blob/215d21f/ai-monitor-version.ini) は `v0.4.0` のまま。
前のバージョンへの追従は [#113](https://github.com/shuhei1101/alias-inject/issues/113)（[PR #114](https://github.com/shuhei1101/alias-inject/pull/114)）。
