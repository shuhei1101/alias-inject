# 要件

## 要望

AI Monitor `v0.5.0` の配布物のうち、alias-inject に有るものを `v0.5.0` に合わせ、配布先の反映作業を alias-inject で済ませる。

| 分類 | 終了の条件 |
| --- | --- |
| サイトのレイアウト | `python -m ai_monitor.distribution import-site --version v0.5.0` で `docs/_theme/` を取り込み、直下の記録 `ai-monitor-theme.yaml` のバージョンが `v0.5.0` になっている。v0.5.0 で配布物から消えた `docs/_theme/assets/vendor/mdmark/` が残っていない |
| 追従のバージョン | [ai-monitor-version.ini](https://github.com/shuhei1101/alias-inject/blob/215d21f/ai-monitor-version.ini) が `v0.5.0` になっている |
| 配布先の反映作業 | [反映作業/index.yaml](./反映作業/index.yaml) の作業ごとに、確認スクリプトが alias-inject で有効になっている結果を返却する |

配布先の反映作業の dry-run の結果は次のとおり（各作業のフォルダの `dry-run.log`）。

| 作業 | dry-run | alias-inject の状態 |
| --- | --- | --- |
| 配布先の mdmark の設定へのノードの種類の記載 | changed | 直下に `mdmark.config.yaml` が無く、`map.kinds`・`map.lines` を持つファイルを新規作成する |
