## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 設計書の分け方 | 1 つの設計書の要素の `container` が 1 つの物理ファイルを指すよう、2 つ目以降の物理ファイルの要素を新しい設計書へ移す | 置き場所と名前は `要件.md` の `未確定` |
| 要素の中身 | 引数・処理・単体テスト・`status`・`introduced` を移す前のまま保つ | - |
| `directory`・`lead` | 分けた設計書ごとに、その物理ファイルとテストのファイルだけを並べる | `入口.yaml` の `.claude-plugin/`・`package.json` などの定義ファイルは `register.tsx` 側に残す |
| `test_files` | その物理ファイルの単体テストのファイル 1 つだけにする | `handlers.test.ts` は `handlers.ts` の設計書へ移す。`types/index.d.ts`・`aliases-schema.ts`・`gen-aliases-schema.mjs` の設計書は持たない |
| 参照 | `callees`・`refs` で移した要素を指す行を、移した先の設計書のパスへ付け替える | `入口.yaml`・`スキーマ.yaml`・`記録.yaml`・`エイリアス.yaml` の中 |
| 目次 | `プラグイン/index.yaml` に分けた先の設計書の行を追加し、`design_docs publish` で README を生成し直す | - |
| 確認 | `design_docs validate` が `物理ファイルが 2 つ以上あります` を 1 件も出さない | 既知の `dev/pr/21`・`dev/pr/41` の `反映作業/index.yaml` のエラーは対象外（`要件.md` の `## スコープ外`） |
