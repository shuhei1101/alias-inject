# 要件

## 要望

`hooks/`（生成物の `hooks/lib/aliases-schema.ts` と `hooks/vendor/` を除く）が出力する警告・エラー・debug log の文字列に残る NG の単語を、knowledge の [AI slop の単語の対応表](https://github.com/shuhei1101/knowledge/blob/develop/docs/word-list/word-list-ai-slop.yaml)（develop）の OK の単語へ置き換える。
同じ文言を記載した設計書（MOD-1・MOD-2・MOD-11）と、文言を期待値に持つテストも同じ文言にする。

- 終わりの条件: `hooks/` の文字列リテラルを対応表の `pattern`（`allow` を除く）で照合し、ヒットが 0 件になる。設計書・テストに、置き換える前の文言が残らない
- 文言のほかに、出力する条件・出力先（debug log・warnings・例外）・付ける値（パス・理由）は変えない
- 置き換え後の文言はユーザーが確認する（[プラグイン](./プラグイン.md) の `## 変更方針` の文言の案）
