## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 文言 | 下の文言の案のとおり、NG の単語だけを対応表の `ok` の単語へ置き換える。`ok` の単語では文が成り立たない箇所は、意味の合う別の単語にする | 確認ログで確定 |
| 設計書 | モジュール構成設計の工程で MOD-1・MOD-2・MOD-11 の文言を案の文言にし、MOD-1 の単体テストの expected を、`照合から除外しました` の debug log は設定ファイル自身を必須の値が空の文書として除外した行（理由 `… が空です`）だけが出ることにする | - |
| テストコード | 実装の工程で handlers.test.ts と prompt-submit.test.ts の期待値を `照合から除外しました` にする | - |
| 既存機能への影響 | 出力する条件・出力先・付ける値は変わらない | 単体・結合テストを全件実行して回帰を確認する |

`変数参照の値を引けません` の「引く」の `ok` は検索・参照で、どちらも値を取得できない事象に合わない。「参照」は「変数参照の値を参照できません」と同じ単語が重なるため、「取得」にする。

推奨: 案のとおり

NG の単語だけを置き換え、文の構造を変えないため、利用者が検索する手掛かり（パス・キー名）が今と同じ位置に残る。
