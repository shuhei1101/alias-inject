# 要件

## 要望

`tests/unit/`・`tests/integration/` のコメント・テスト名・入力の値、ルートの `README.md`・`CLAUDE.md`、`skills/global-setup/SKILL.md`、`scripts/gen-aliases-schema.mjs` のコメントに残る NG の単語を、knowledge の [AI slop の単語の対応表](https://github.com/shuhei1101/knowledge/blob/develop/docs/word-list/word-list-ai-slop.yaml)（develop）の OK の単語へ置き換える。

- 終わりの条件: 対象のファイルを対応表の `pattern`（`allow` を除く）で照合し、ヒットが 0 件になる。ヒットを残す箇所は、残す理由をスコープ外に記載したものだけにする
- 置き換えでテストが検証する内容・スキルの手順・コードの動作を変えない
- テストの期待値のうち、`hooks/` が出力する文字列は変えない
- テストの入力の値を置き換えるときは、同じ値を記載した設計書（MOD-17 の `description: 設計書を引く` 等）も合わせて置き換える

プロジェクトの用語「語」（照合する語・語の指す文書・文脈に出す語）は、#89 の決定のとおり「単語」へ置き換える。
