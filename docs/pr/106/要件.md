# 要件

## 要望

設計書の検査を knowledge の `design-schemas/v8.1.0` のスキーマの参照へ移し、`schemas/` から AI Monitor から配られたスキーマのコピーを削除する。
あわせて、knowledge のアーキテクチャ図のスキーマに合わせて `ARCH-1.yaml` から `repository.layout` を削除する。

- 終わりの条件
  - `docs/architecture/ARCH-1.yaml` に `repository.layout` が無い
  - `project-index.yaml` の設計書の種類の行の `schema` が knowledge のスキーマの `source`・`path`・`ref` を持つ（設計書の種類の行は `schemas/design/{種類}.schema.yaml`、管理用の YAML の `docs` の行は `schemas/knowledge-files.schema.yaml`）
  - `schemas/` に `aliases.schema.yaml` だけが残る（AI Monitor から配られたコピーの 19 件を削除する。フェーズの設計書を持たないため `phase.schema.yaml` も削除する）
  - 削除したコピーを指す記述（`CLAUDE.md`・`docs/guide/files.yml` の `$schema` の行・`LAY-1.yaml` の `schemas/` の `contents`）が残らない
  - 全ての設計書と `docs/guide/files.yml` が、参照する knowledge のスキーマの検査に違反 0 件で合格する
