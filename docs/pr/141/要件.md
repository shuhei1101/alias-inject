# 要件

## 要望

引用の文脈を追加したときに利用者の画面に表示する行（入力・ツールの結果・応答の文の 3 つの経路で共通）の頭の文言を `文脈を追加: ` から変え、行の頭でどのプラグインが表示した行かが分かるようにする。

- 頭より後ろの `{単語}（{id}）、…` の書式・表示する条件・`show_added` の扱いは変えない

`未確定`: 行の頭の文言（決める段: インターフェース定義設計）

[LIB-1](https://github.com/shuhei1101/alias-inject/blob/3ceef9b/docs/library/LIB-1.yaml) の `$.ui.log` の確認済みの範囲では、Claude Code は `transcript` の行を `● {プラグインの名前}: {テキスト}` で表示する。
Issue の指定どおり `alias-inject: ` にすると、画面では `● alias-inject: alias-inject: 文書（document）` になる。

| 案 | 画面の表示の例 | メリット | デメリット |
| --- | --- | --- | --- |
| A | `● alias-inject: alias-inject: 文書（document）` | Issue の指定どおり。Claude Code が名前を付けない表示でもプラグインが分かる | Claude Code が付ける名前と重なり、幅が増える |
| B | `● alias-inject: 文書（document）`（行の頭の文言をなくす） | 幅が最も短く、Claude Code が付ける名前でプラグインが分かる | Claude Code が名前を付けない表示ではプラグインが分からない |

推奨: B

Issue の目的（どのプラグインの行かが分かり、幅を使わない）を、Claude Code が付ける名前で満たせるため。
