# 要件

## 要望

`project-index.yaml` の設計書のスキーマの `ref` を、`generated_from.source`・`tracked` を含む knowledge の `design-schemas` のタグへ上げ、`docs/layout/LAY-1.yaml` の複製の元と git で管理する理由を `generated_from` へ移す。

- 終わりの条件
  - `project-index.yaml` の knowledge のスキーマを参照する全ての行の `ref` が、`generated_from.source`・`tracked` を含むタグを指す
  - リポジトリの外を元にする複製（`hooks/vendor/`・`docs/_theme/`）のエントリが、`generated_from.source` に元とバージョンを持ち、`contents` に複製の元を記載していない
  - git で管理する生成物・複製（`hooks/lib/aliases-schema.ts`・`hooks/vendor/`・`docs/_theme/`）のエントリが、`generated_from.tracked` に git で管理する理由を持つ
  - 全ての設計書と `docs/guide/files.yml` が、上げたタグのスキーマの検査に違反 0 件で合格する

`ref` を上げる先のタグは、[shuhei1101/knowledge#392](https://github.com/shuhei1101/knowledge/issues/392) で作成する。
