# 要件

## 要望

直下の `project-index.yaml` の最上位に、配信元の `description` と `when` を記載する。

- `description`: 配信元が持つ文書（alias-inject のプラグインの設計書・公開ドキュメント）を 1 行で記載する
- `when`: どういうときにこの配信元で検索するかを 1 行ずつ記載する。1 行目には最もよく使用する場面を記載する（文書の MCP の instructions には 1 行目だけが表示される）
- 書いた後の `project-index.yaml` が、project-index の develop のスキーマ `schemas/project-index.schema.json` の検証に通る
