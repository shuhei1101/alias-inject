# 設定ファイル

設定ファイルの項目・既定値・`type` ごとの列の一覧

## 設定ファイルの場所

設定ファイルは YAML で、パスを `~/.claude/settings.json` の `env` の `ALIAS_INJECT_CONFIG` に指定する。
先頭の `~` はホームに展開する。
読むのはユーザースコープの `settings.json` だけで、プロジェクトスコープの `env` は読まない。
`ALIAS_INJECT_CONFIG` が無いときは、何も追加せずに入力をそのまま渡す。

置き場所の例は `~/.config/alias-inject/settings.yaml`。
入力の送信ごとに、設定ファイルと照合する YAML の更新時刻を確かめ、変わったものだけ読み直す。

## 最上位のキー

| キー | 中身 |
| --- | --- |
| `global` | 全てのプロジェクトで使う設定 |
| `projects` | プロジェクトごとの設定。`match` が当たった要素だけを `global` に重ねる |

## global のキー

<!-- table: data -->

| キー | 型 | 必須 | 既定値 | 説明 |
| --- | --- | --- | --- | --- |
| `enabled` | boolean | - | `true` | `false` のときは何も追加しない |
| `sources` | object[] | - | なし | 照合するソース。キーは [sources の要素のキー](#sources-の要素のキー) |
| `origins` | `user` / `plugin` の並び | - | すべての出所 | 文脈を追加する入力の出所 |
| `max_items` | integer | - | `20` | 1 回に追加する語の上限。1 以上の整数で、それ以外の値は既定を使う |
| `max_chars` | integer | - | `4000` | 1 回に追加する文脈全体（見出しを含む）の文字数の上限。1 以上の整数で、それ以外の値は既定を使う |
| `exclude` | string の並び | - | なし | 照合しない語。入力・語と同じ正規化をしてから比べる |
| `heading` | string | - | `この発言に出る用語` | 追加する文脈の先頭に置く見出し |

<!-- /table -->

`origins` の値は次のとおり。
書かないとき、空の並びのとき、許す値が 1 つも無い並びのときは、すべての出所が対象になる。
それ以外の値は無視する。

| 値 | 対象の入力 |
| --- | --- |
| `user` | 利用者の入力。tmux から送る ai-monitor の指示を含む |
| `plugin` | プラグインが送信した入力 |

## sources の要素のキー

<!-- table: data -->

| キー | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `label` | string | 必須 | 文脈の中で、このソースの語を並べるセクションの見出し |
| `type` | `term` / `doc` / `command` / `url` | 必須 | 追加する列と書式を決める引用の種類 |
| `files` | string / string の並び | 必須 | 照合する YAML のパスか glob |
| `id` | string | 必須 | 項目の ID を持つ列の名前 |
| `words` | string の並び | 必須 | 照合する語（用語とエイリアス）を持つ列の名前 |
| `description` | string | - | 項目の説明を持つ列の名前 |
| `related` | string | - | `term` のとき、関連する文書の並びを持つ列の名前 |
| `mcp` | string | - | `doc` のとき、文書を詳しく引く MCP サーバーの名前 |
| `command` | string | - | `command` のとき、コマンドを持つ列の名前 |
| `cwd` | string | - | `command` のとき、実行するフォルダを持つ列の名前 |
| `url` | string | - | `url` のとき、URL を持つ列の名前 |

<!-- /table -->

- `label`・`type`・`files`・`id`・`words` のどれかが無い、または `type` が上の 4 つ以外のソースは、照合から外す
- `files` の glob は、`*` がフォルダの区切りを除く任意の文字列、`**` が任意の深さのフォルダに当たる
- `files` の先頭の `~` はホームに展開する。相対パスは、`global` の中なら設定ファイルのフォルダから、`projects` の中なら起動したプロジェクトの直下から解決する
- `words` の列の値が並びなら、要素ごとに照合する。最初の列の値が、文脈に出す語になる
- `mcp` は列の名前ではなく、MCP サーバーの名前そのものを指定する

## type ごとに追加する列

追加する文脈には、どの `type` でも語と `id` を並べる。
続く列は `type` ごとに次のとおりで、値のあるものだけを並べる。

| type | 追加する列 | 用途 |
| --- | --- | --- |
| `term` | `description`・`related` | 用語。`related` は関連する文書の ID と名前 |
| `doc` | `description`・`mcp` | 文書。`mcp` で詳しく引く MCP サーバーを案内する |
| `command` | `command`・`cwd`・`description` | コマンド |
| `url` | `url`・`description` | URL |

## projects の要素のキー

| キー | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `match` | string | 必須 | 絶対パスかプロジェクト名 |
| `sources` | object[] | - | `match` が当たったときに `global.sources` の後ろへ重ねるソース |

`match` は次のときに当たる。

| 指定 | 当たるとき |
| --- | --- |
| 絶対パス | 起動したプロジェクトの直下が、そのパスかその配下 |
| プロジェクト名 | リポジトリのフォルダ名が一致する |

worktree は、本体のパスとフォルダ名で見る。

### 重ね方

`projects` の要素は、`global` と同じキーを持てる。
当たった要素を並びの順に `global` へ重ねる。
`sources` と `exclude` は後ろに追加し、それ以外のキーは置き換える。
別のソースにある同じ語は、どちらも追加する。

## 設定の例

```yaml
global:
  sources:
    - label: 用語
      type: term
      files: ~/knowledge/docs/term/*.yaml
      id: id
      words: [name, aliases]
      description: description
      related: related
  max_items: 20
  max_chars: 4000
  exclude: [それ]
projects:
  - match: sample
    sources:
      - label: コマンド
        type: command
        files: docs/command/*.yaml
        id: id
        words: [name]
        command: command
        description: description
```
