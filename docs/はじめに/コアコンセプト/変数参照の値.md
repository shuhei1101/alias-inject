# 変数参照の値

読んだ本文の `!{名前}` に、同じ名前の環境変数の値を文脈として追加する仕組み

## 何が起きるか

Read・Bash・MCP のツールの結果の本文に `!{名前}` の変数参照があると、同じ名前の環境変数の値を、ツールの結果の後ろの文脈としてモデルにだけ追加する。
変数参照の名前は、英字かアンダースコアで始まり、英数字とアンダースコアが続くものだけ。
本文は置き換えず、そのまま渡す。
値は Claude Code を起動した環境の環境変数から引く。

同じ名前が本文に何度出ても、その名前の行は 1 行だけ追加する。

次の結果には追加しない。

- 本文に変数参照が無い結果
- エラーの結果
- 他のフックが実行を拒んだ結果

値を引けないときも、ツールの結果は止めずにそのままモデルに渡す。
引けなかった理由は、Claude Code の debug log に出る。

> [!NOTE]
> 本文に名前が書かれた環境変数の値はモデルに渡る。
> 秘密の値の名前を書いたファイルを読ませると、その値も文脈に入る。

## 文脈の書式

名前ごとに 1 行にして、1 つの文脈にまとめる。

| 環境変数 | 行 |
| --- | --- |
| 設定されている | `変数参照の値: !{名前} = {値}` |
| 設定されていない | `変数参照の値: !{名前} は環境変数が設定されていない` |

値に改行を含むときだけ、値を JSON の文字列（`"line1\nline2"`）で書いて 1 行に収める。

```text
変数参照の値: !{AI_MONITOR_ROOT} = /mnt/c/Users/shuhe/repo/ai-monitor/.claude/worktrees/develop
変数参照の値: !{DOCS_PORT} は環境変数が設定されていない
```

## 追加する量の上限

| 項目 | 上限 | 超えたとき |
| --- | --- | --- |
| 1 回に値を追加する名前 | 50 名前 | 本文に出た順で 50 名前までの行を作り、最後に `変数参照の値: ほか {件数} 件の変数参照は値を追加していない` の 1 行を置く |
| 1 つの値の長さ | 1000 文字 | 先頭だけを書き、行の末尾に `（{全体の文字数} 文字のうち先頭 1000 文字）` を添える |
| 値を引く待ち時間 | 20ms | 値を引けなかったものとして、文脈を追加せずに結果をそのまま渡す |

設定ファイルのキーは無い。
設定ファイルが無くても動く。
